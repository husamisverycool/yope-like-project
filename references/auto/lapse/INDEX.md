# lapse references (SOURCED)

App: **Lapse - Disposable Camera** (Lapse Ltd, London), iOS `id1636699256`, bundle `com.lapse.journal`, listing
version **4.1.1** (released 2025-12-06; release note: "Lapse has returned to its roots as a disposable-camera app").
iOS only (lapse.app FAQ: "We are currently iOS only"). The listing has **no App Preview video** (checked 2026-10-16).
Used as a **mechanics** reference only for `camera.overnight` (owner decision 2026-10-15). Research:
`design/research/overnight-and-questions.md`.

Scale: `lapse-store-01.png` (1242 × 2688) is a full-width screen render (the photo, control row and corners run to the
image edges; no phone frame). `lapse-store-05.png` shows the same camera inside a mock-up whose screen spans x 87.5–1153.5
(1066 px). The shutter outer diameter is 0.2545 × the screen width in **both** (316.1 / 1242 and 271.2 / 1066), so the
render device is unknown and values are given as **fractions of screen width**, converted to Jolt's 393-pt screen
(pt = fraction × 393). The `se-*` panels (1242 × 2208) are composites; ratios only.
