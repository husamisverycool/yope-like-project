Fallback fonts for server-rendered text (worker tribute cards and captions, web invite share image og.png).
The app's own faces (Roboto Serif Title / Headline, Inter) cover Latin and Cyrillic (Inter also Greek); these
files supply the glyphs they lack, so names and lines in other scripts or with emoji do not render as tofu.
All are SIL Open Font License 1.1 (licence files next to them; no Reserved Font Name is used: the CJK fonts'
RFN is 'Source', these keep their Noto names). Downloaded 2026-10-16; processed with fontTools 4.67.0
(fontTools.varLib.instancer, fontTools.subset). Which consumer reads which file: worker
backend/worker/fonts/fonts.conf (scripts/ + emoji-color/), web web/assets/fonts/fonts.conf (scripts/ + emoji-mono/);
their aliases list the fallback order. The emoji fonts sit in separate folders because fontconfig must not see both:
given the monochrome one, Pango drew 🎉 / 👩🏽‍🦱 / 🇧🇷 from it in the worker.

Upstream: google/fonts (https://raw.githubusercontent.com/google/fonts/main/ofl/<family>/…) unless noted.
