# Verification — `groups.screen` (Android)

The group: cover, serif name, members, actions, this week's strip, members' weeks + memory cards pager, earlier grid — `groups/GroupScreen.kt`.

Pass 4 (Retro redesign). Generated by `android/feature/account/verification/checklists.py` from the Robolectric renders (`./gradlew :feature:account:recordRoborazziDebug`, debug build, 393 × 852 dp at 2 px/dp, no system-bar insets, Reduce Motion off, font scale 1, real sample photos). Memory entries (memory pass APIs `OnThisDayEntry`, `YearStoryEntry`, `BirthdayRequestEntries`): this screen draws the birthday request row (C-14 + C-16) above this week and the feed cards (C-18 frame, Rewind / Recap glyph) in the members' pager; `groups.screen/default-memoryEntries` renders them with the memory copy.
